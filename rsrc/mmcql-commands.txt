Help
\?              show help on backslash commands
\h              show help on syntax of SQL commands

Input/Output
\o [file]       send all query results to file

Informational
\d              list tables (categories)
\d [table]      describe table

Formatting
\a [on|off]     toggle between aligned and unaligned output mode
\f [string]     show or set field separator for unaligned output
\t [on|off]     toggle show only rows output mode
\C [on|off]     toggle mmCIF output mode

Datablock
\b [datablock]  select datablock from current cif file
